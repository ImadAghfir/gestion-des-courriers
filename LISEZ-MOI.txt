CORRECTIONS DU SYSTEME DE NOTIFICATIONS
Application de Gestion des Courriers v3.3

INSTALLATION
------------
1. Extraire cette archive DANS le dossier du projet
   (C:\Users\IM3DD\gestion-courriers) en acceptant le remplacement
   des fichiers existants. L'arborescence est identique :

   backend\notifications\services.py
   backend\notifications\views.py
   backend\notifications\tests.py
   backend\notifications\management\commands\verifier_echeances.py
   frontend\src\App.jsx

2. Redemarrer le serveur Django (nouvelles routes API) :
   cd backend
   .venv\Scripts\activate
   python manage.py runserver

3. Rafraichir la page du navigateur (frontend Vite recharge tout seul).

AUCUNE MIGRATION N'EST NECESSAIRE.

   python manage.py test notifications

CE QUI A CHANGE
---------------
- Correction : un courrier sortant deja envoye n'est plus signale en retard.
- Robustesse : une panne du controle des echeances ne bloque plus l'acces
  aux notifications.
- Les comptes desactives ne recoivent plus d'alertes d'echeance.
- Liste limitee aux 50 notifications les plus recentes ; compteur de non-lues
  calcule cote serveur (routes /api/notifications/compteur/ et
  /api/notifications/tout-marquer-lues/).
- Purge automatique des notifications LUES de plus de 90 jours lors du
  controle quotidien (les non-lues ne sont jamais supprimees).
- Interface : bouton "Tout marquer comme lu" et resume "X non lues sur Y".
